# Project Index

Last updated: 2026-08-30

## Purpose

Operator map for the paper workspace. Use this file to keep the control
surfaces visible and prevent the paper from dissolving into one large draft
plus chat memory.

## Primary Writing Surfaces

- `docs/Artifact-First Engineering.md` — main paper draft
- `docs/Artifact-First Engineering KATIE.md` — separate authored candidate; master evidence basin preserved
- `docs/Artifact-First Engineering - Extensive Paper Prompt and Outline.md` — long-form prompt and outline
- `docs/Artifact-First Engineering - Discussion Tracker.md` — argument and structure tracker
- `docs/vocabulary.md` — source-labeled operating vocabulary and translation rules
- `docs/SOURCE_DOCUMENT_INDEX.md` — source authority, retrieval tags, and integration map
- `docs/source_index.md` — citable external, case, and private-context source ledger

## Control Surfaces

- `00_CONTROL/TIME_LOG_SCHEMA.md` — rules for recording writing time
- `00_CONTROL/time_log.csv` — writing-session ledger
- `00_CONTROL/DECISION_PATH.md` — unresolved or resolved editorial and packaging decisions
- `00_CONTROL/RISK_REGISTER.md` — drift, overclaim, evidence, and production risks for the paper package

## Session Reporting

- `.Executive_Correspondence/` — append-only BLACKBOX-style session reports
- `scripts/session-close.mjs` — closes a writing session by summarizing time and appending a report

## Conventions

- Keep Markdown as the primary working surface.
- Treat time tracking as evidence, not vibes.
- Append; do not rewrite history out of the record.
- Use `DECISION_PATH.md` for meaningful editorial/package choices, not tiny prose tweaks.
